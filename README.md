# Hira Skills

Custom skills collection for AI agent platforms including Antigravity, Claude Code, and Cursor.

## Included Skills

### tech-vid-script-v3

A video scriptwriting skill designed for YouTube technology tutorials and troubleshooting guides.

#### Highlights
- **Beginner-Friendly**: Focuses on clear visual on-screen navigation rather than complex keyboard shortcuts.
- **Natural Voiceover Rhythm**: Keeps actions concise (5-10 words per bullet point) with conversational transitional phrases.
- **Clean Formatting**: Formats UI click targets in bold and avoids unnecessary quotation marks.
- **Interactive Flow**: Offers customizable introduction and outro hooks tailored to the specific topic.
- **Word Document Builder**: Includes a PowerShell utility to automatically generate formatted .docx files.

## Setup & Installation

### Antigravity Workspace
Copy the `tech-vid-script-v3` folder to `.agents/skills/` in your workspace directory:
```
.agents/skills/tech-vid-script-v3/
```

### Global Installation
Place the folder in your global skills folder:
- Windows: `%USERPROFILE%\.gemini\antigravity\skills\tech-vid-script-v3`
- macOS/Linux: `~/.gemini/antigravity/skills/tech-vid-script-v3`
